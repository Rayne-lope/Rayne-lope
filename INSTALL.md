# INSTALL

1. Create/open the special GitHub profile repository:
   `Rayne-lope/Rayne-lope`

2. Put these files in the repository root:

   README.md
   assets/hero.svg
   assets/projects-divider.svg
   assets/footer.svg
   assets/city.gif

3. Commit and push.

## Font note

Normal GitHub Markdown cannot force a custom local/web font.
The SVG headers request `Departure Mono` first and fall back to a monospace font if
the viewer does not have it available. To guarantee the exact typeface visually,
the headings must be pre-rendered to paths/raster using the font. No font file is
included in this package.
